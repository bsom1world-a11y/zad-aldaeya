# زاد الداعية | إعداد المحاضرات الدعوية 🌿

نسخة بسيطة تعمل فعليًا — افتحي `index.html` في المتصفح مباشرة (بدون تثبيت).

## ما يعمل الآن
- الرئيسية + زر «إنشاء محاضرة جديدة» بكل الحقول المطلوبة (العنوان، الفئة، المدة، النوع، الأسلوب، الملاحظات).
- زر «إعداد المحاضرة» **لا يعرض نصوصًا وهمية**: بدون تفعيل خدمة AI تظهر رسالة واضحة تطلب التفعيل، مع خيار «هيكل فارغ» معلن أنه ليس محتوى جاهزًا.
- عند تفعيل الخدمة (الإعدادات) يُولّد مسودة بالأقسام العشرة المطلوبة مع قواعد الضبط العلمي ووسم «يحتاج إلى مراجعة».
- تعديل + حفظ محلي (localStorage) + بحث + نسخ + تصدير Word + تصدير PDF/طباعة + نسخة مختصرة نقاط للإلقاء + نسخة احتياطية JSON.
- تصميم عربي RTL، أخضر زيتوني/أبيض/بيج، متجاوب مع الجوال.

## تفعيل الذكاء الاصطناعي (آمن)
1. شغّلي `server-example.js` على جهازك/خادمك وضعي المفتاح فيه كمتغير بيئة (لا يظهر في المتصفح).
2. الصقي رابط الخادم في صفحة الإعدادات ← حفظ ← «اختبار الاتصال».

## ملاحظة شرعية
المسودات المولّدة تُراجَع قبل الإلقاء. أي دليل غير متحقق منه موسوم بـ «يحتاج إلى مراجعة».
